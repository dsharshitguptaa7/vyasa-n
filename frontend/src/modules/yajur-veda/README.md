# Yajur Veda Frontend Module
**Domain:** Research Administration & Incentives  
**Parent System:** VYASA Ecosystem (CSJMU)  
**Status:** Planned Architectural Boundary

## Overview
Yajur Veda automates administrative and financial workflows for faculty and scholars, including research grants, incentive disbursements, project sanction tracking, and compliance clearances.

## Module Structure
- `index.ts`: Module entrypoint.
- `routes.tsx`: Sub-route definitions mounted under `/modules/yajur-veda`.
- `pages/`: Page-level dashboard and administration components.
- `components/`: Domain UI widgets.
- `services/`: API client interactions.
- `types/`: Domain TypeScript contracts.
