# Centralized Ecosystem Fonts

This directory houses ecosystem-wide font packages and offline font distributions for air-gapped institutional environments.

## Font Stacks

- **Primary UI**: Noto Sans (Latin / Devanagari)
- **Devanagari Font**: Noto Sans Devanagari, Mukta
- **Scholarly Heading**: Cinzel, Noto Serif Devanagari

By default, web clients stream optimized subsets via preconnected Google Fonts with local system fallbacks (`Mukta`, `Kohinoor Devanagari`, `Mangal`, `Nirmala UI`).
